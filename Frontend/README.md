# 🎨 Pixora Frontend

The frontend of **Pixora**, a modern full-stack social media platform built with **React.js** and **Vite**.

It provides a modern, responsive, and interactive user interface that communicates with the FastAPI backend through REST APIs for authentication, user profiles, posts, likes, comments, follows, saved posts, stories, reels, chats, notifications, and more.

---

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/abdullahshabir31/Pixora-Project.git
```

```bash
cd Pixora-Project/Frontend
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment Variables

Create a `.env` file:

```env
VITE_API_URL=http://127.0.0.1:8000
```

---

## Run Development Server

```bash
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```
